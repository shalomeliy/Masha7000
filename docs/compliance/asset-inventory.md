# רשימת נכסים וסיווג מידע

טיוטה 0.1, 2026-11-13. בעלים של כל הנכסים: המפעיל, אלא אם כתוב אחרת. נבדק פעם בשנה.

## סיווג (A.5.12, A.5.13)

| רמה | מה זה | דוגמה | טיפול |
|---|---|---|---|
| **סודי** | נותן גישה למערכת או לנתונים | `SESSION_KEY`, טוקנים, מפתחות API, סוד TOTP | רק בהגדרות Vercel או מוצפן; אף פעם בקוד, ביומן או בצ'אט |
| **אישי רגיש** | מידע מזהה על אנשים | טלפון, ת"ז, אילוצים ובריאות (מחלה) של עובד | נשאר ב-Drive של הלקוח; בשרת רק מוצפן או כ-hash |
| **פנימי** | מידע תפעולי של הלקוח | משמרות, עבודות, רכבים | ב-Drive של הלקוח |
| **ציבורי** | | קוד המקור של דפי האתר, דפי פרטיות | |

## נכסי מידע

| נכס | איפה | סיווג | הגנה | כמה זמן נשמר |
|---|---|---|---|---|
| עובדים, משמרות, עבודות, רכבים, הגדרות | Google Drive של הלקוח (appDataFolder) | אישי / פנימי | OAuth של הלקוח, הרשאה `drive.appdata` בלבד | כל עוד הלקוח שומר |
| אירועי משמרות | Google Calendar של הלקוח (יומן "Smart Shifts") | פנימי | `calendar.app.created` בלבד | כמו לעיל |
| גיבוי שבועי | Drive של הלקוח | אישי / פנימי | כמו לעיל | |
| טוקן הרענון של הבעלים | Upstash `owner:refresh` | סודי | AES-256-GCM | עד ניתוק |
| כניסות | Upstash `sess:*` | סודי | AES-256-GCM, עוגיית `__Host-` | 180 יום |
| סודות אימות דו-שלבי וקודי גיבוי | Upstash `mfa:*` | סודי | מוצפן; קודי גיבוי כ-hash | עד איפוס |
| רשימת מנהלים מורשים | Upstash `allowed` | פנימי | | |
| טפסי הצטרפות ואילוצים ותשובות | Upstash `join:*`, `cons:*` | אישי רגיש | מוצפן; טלפון ות"ז כ-hash עם מפתח | עד שהמנהל מושך אותם |
| יומן אבטחה | Upstash `audit-log` | פנימי (מכיל מיילים) | מוצפן, IP מקוצר | 1000 אחרונים |
| יומן "מה הלך ל-Claude" | Upstash `claude-log` | אישי | מוצפן | מוגבל באורך |
| יומן קריאות API | Upstash `api-log` | פנימי | בלי גוף הבקשה | מוגבל באורך |
| מפתחות API חיצוניים | Upstash `apikey:*` | סודי | רק hash של המפתח | עד ביטול |
| דיווחי שגיאות | Sentry (EU) | פנימי | בלי PII, בלי query, קצוץ ל-300 תווים | לפי Sentry (90 יום בחינם) |
| קוד המקור | GitHub `shalomeliy/Masha7000` | פנימי | פרטי, אימות דו-שלבי (לוודא) | |

## נכסי תוכנה ושירות

| נכס | תפקיד |
|---|---|
| Vercel (פרויקט masha7000) | אחסון, פונקציות שרת, הגדרות סביבה (כל הסודות) |
| Upstash Redis | מאגר השרת |
| Google Cloud (פרויקט OAuth) | Client ID וסוד, מסך הסכמה |

## סודות (מפורט ב-`key-management.md`)

`SESSION_KEY`, `SESSION_KEY_PREVIOUS` (רק בזמן החלפה), `GOOGLE_CLIENT_SECRET`, `KV_REST_API_TOKEN` / `REDIS_URL`, `ANTHROPIC_API_KEY`, `RESEND_API_KEY`, `CLAUDE_LOG_TOKEN`, `VITE_SENTRY_DSN` (לא סודי באמת, נשלח לדפדפן).

## מכשירים (A.5.9, A.8.1)

| מכשיר | שימוש | דרישות (לוודא ולסמן) |
|---|---|---|
| המחשב של המפעיל (SHELPC22) | פיתוח, ניהול ספקים | הצפנת דיסק (BitLocker) ☐, נעילת מסך ☐, עדכונים אוטומטיים ☐, אנטי-וירוס ☐ |
| הטלפון של המפעיל | אפליקציית אימות, ניהול | נעילה ביומטרית ☐, הצפנה ☐ |

`.env.local` במחשב הפיתוח מכיל מפתחות אמיתיים (בחירת המפעיל, לבדיקות ידניות). הוא מוחרג מ-git. סיכון מכוסה ב-R3 ובהצפנת הדיסק.
