# גיבוי, שחזור והמשכיות

טיוטה 0.1, 2026-11-13 (A.5.29, A.5.30, A.8.13, A.8.14). **מאושר: ______**

## מה מגובה

| מה | איך | איפה | תדירות |
|---|---|---|---|
| כל הרשימות של הלקוח (עובדים, משמרות, עבודות, רכבים, הגדרות) | עותק אוטומטי בפתיחה הראשונה של כל שבוע | Drive של הלקוח, תיקיית האפליקציה | שבועי |
| אותו דבר, ידני | הגדרות ← גיבוי ← עותק או הורדה לקובץ JSON | Drive / המחשב של המנהל | לפי הצורך; **מומלץ להוריד לקובץ פעם בחודש** |
| Drive עצמו | שרידות של Google | Google | (הספק) |
| קוד | git, GitHub | GitHub + המחשב | כל שינוי |
| מאגר השרת (Upstash) | **אין גיבוי** | | ראה למטה |

**למה אין גיבוי למאגר השרת:** הוא מחזיק כניסות, אימות דו-שלבי, טפסים ממתינים ויומנים, לא את נתוני הלקוח. אם הוא נמחק: כולם מתחברים מחדש ומגדירים אימות מחדש, הבעלים מחבר Drive מחדש ומוסיף את המנהלים, וטפסים שלא נמשכו אובדים. היומנים אובדים. מקובל בשלב הזה; אם זה ישתנה, Upstash מציע גיבוי יומי בתוכנית בתשלום.

## שחזור

- הגדרות ← גיבוי ← בחירת עותק או קובץ ← שחזור. הקובץ נבדק כ"לא אמין": JSON בלבד, עד 20MB, וכל רשימה חייבת להיות בצורה הנכונה.
- **בדיקת שחזור פעם ברבעון:** לשחזר עותק לחשבון בדיקה (חשבון Google אחר) ולוודא שהעובדים והמשמרות מופיעים. לרשום ב"יומן הבקרה". בלי זה, הגיבוי הוא הנחה, לא ראיה.
