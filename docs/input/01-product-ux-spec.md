# Product Specification: ShiftSmart PWA (Manager Dispatcher Edition)

## 1. Project Overview
ShiftSmart היא אפליקציית Web ניידת (PWA) המיועדת למנהלים לניהול סידור עבודה 24/7, אילוצי עובדים, משמרות כוננות, ותפקידים מבצעיים. האפליקציה מתארחת בחינם ב-Vercel ומנהלת את כל נתוניה ישירות מול חשבון ה-Google (Calendar & Drive AppData) של המנהל, ללא שרת מרכזי או מסד נתונים חיצוני (Zero Server Data Retention).

## 2. Core Features & User Stories
1. **Google Authentication & Cloud Storage:**
   - התחברות מהירה באמצעות Google OAuth 2.0.
   - יקטוריה ושמירה אוטומטית של סידור העבודה ביומן ייעודי (`Smart Shifts`) ושל הגדרות מערכת/עובדים ב-Google Drive AppData.
2. **ניהול עובדים ותפקידים (Roles & Certifications):**
   - הגדרת רשימת תפקידים גלובלית בארגון (למשל: אחראי משמרת, מוקדן, טכנאי).
   - לכל עובד מוגדר פרופיל הכולל שם, פרטים, ותפקידים מורשים.
3. **משמרות 24/7 ומשמרת כוננות (Standby On-Call):**
   - מערכת תומכת במשמרות סביב השעון (בוקר, צהריים/ערב, לילה).
   - בכל יממה מוגדרת חובה למשמרת **כוננות (Standby)** המורכבת בדיוק מ-**3 אנשי צוות** הממתינים לקריאה בבית.
   - לכל משמרת (רגילה או כוננות) מוגדרים מראש אילו תפקידים נדרשים לאיוש.
4. **הזנת אילוצים חכמה וקולית (Text & Voice Constraints):**
   - תיבת טקסט חופשי להדבקת הודעות וואטסאפ גולמיות של עובדים.
   - כפתור מיקרופון (Voice-to-Text באמצעות Web Speech API בעברית) המאפשר למנהל להכתיב אילוצים בקולו.
5. **אלגוריתם שיבוץ ובדיקת פערים (Smart Gap Analysis):**
   - הצגת תמונת מצב בזמן אמת של איוש המשמרות.
   - זיהוי אוטומטי של התנגשויות אילוצים או מחסור בעובדים בעלי התפקיד הנדרש, והצגת התראות אדומות ברורות.
6. **ארכיון היסטורי (6 חודשים אחורה):**
   - שמירה וצפייה בהיסטוריית המשמרות עד חצי שנה אחורה לצרכי מעקב ובקרה.

## 3. UI/UX & Design Guidelines (Mobile-First PWA)
- **Layout & Responsiveness:** מותאם לחלוטין לטלפון נייד (Mobile-First Layout) לשימוש ביד אחת, עם Bottom Navigation Bar קבוע (למשל: יומן, עובדים, דוחות/ארכיון, הגדרות).
- **Design System:** 
  - צבעי מותג נקיים ומקצועיים (Tailwind CSS + Shadcn/ui / Lucide Icons).
  - מצב כהה/בהיר אוטומטי או עיצוב כהה מודרני (Dark Mode Preferred).
- **Visual Indicators & Status Badges:**
  - חיווי צבעוני למשמרות ותפקידים (✅ מאויש תקין, ❌ חסר עובד לתפקיד, ⚠️ התנגשות אילוץ).
  - כרטיסיות נקיות (Cards) למשמרות 24/7 ולצוות הכוננות היומי (3 אנשים).
